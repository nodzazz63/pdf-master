# 📑 PDF & Image Master (เว็บแอปจัดการและแปลงไฟล์ PDF & รูปภาพ)

เว็บแอปพลิเคชันสำหรับจัดการและแปลงไฟล์ **PDF** และ **รูปภาพ** แบบครบวงจร ด้วย UI ที่สวยงามทันสมัย รองรับภาษาไทย 100% สลับโหมด Dark/Light ได้ พร้อมความเร็วสูงและความปลอดภัยสูงสุด (ไฟล์ไม่ถูกส่งออกนอกเครื่อง)

---

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: ดับเบิลคลิกไฟล์เดียว (ง่ายที่สุด)
ดับเบิลคลิกที่ไฟล์:
```
start.bat
```
ระบบจะเปิดเซิร์ฟเวอร์และเปิดหน้าเว็บเบราว์เซอร์ที่ [http://localhost:3000](http://localhost:3000) ให้โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
```bash
node server.js
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

## 🛠️ ฟีเจอร์ทั้งหมดที่มีในระบบ (16 เครื่องมือครบครัน)

### 📄 หมวดหมู่ PDF:
1. **PDF เป็น Word (.docx)** — แปลง PDF เป็นไฟล์ Word สำหรับนำไปแก้ไขข้อความต่อได้ทันที
2. **PDF เป็น รูปภาพ (PNG / JPG / WebP)** — แปลงทุกหน้าของ PDF เป็นภาพความละเอียดสูง สามารถเลือก DPI (150, 200, 300) แล้วดาวน์โหลดเป็นไฟล์ ZIP ได้ทันที
3. **PDF เป็น ข้อความ (.txt)** — สกัดข้อความภาษาไทยและอังกฤษทั้งหมดออกมาเป็นไฟล์ Text
4. **รวมไฟล์ PDF (Merge PDF)** — นำหลายไฟล์ PDF มารวมเป็นเอกสารเล่มเดียว
5. **แยกไฟล์ PDF (Split PDF)** — แยกทุกหน้า (1 หน้าต่อ 1 ไฟล์) หรือเลือกช่วงหน้า เช่น `1-3, 5, 7-9`
6. **ดึงเฉพาะหน้า (Extract Pages)** — เลือกหน้าที่ต้องการ เช่น หน้า `1, 3, 5` ออกมาเป็นไฟล์ PDF ใหม่
7. **ลบหน้า PDF (Delete Pages)** — ตัดหน้าที่ไม่ต้องการทิ้ง เช่น ลบหน้า `2, 4`
8. **หมุนหน้า PDF (Rotate Pages)** — หมุนเอกสาร 90°, 180°, 270° ทั้งเอกสารหรือเลือกเฉพาะบางหน้า
9. **บีบอัดลดขนาด PDF (Compress PDF)** — ลดขนาดไฟล์ PDF ให้เล็กลงพร้อมแสดงเปอร์เซ็นต์พื้นที่ที่ประหยัดได้
10. **ใส่ลายน้ำ PDF (Watermark)** — ประทับตราข้อความลายน้ำ (เช่น "CONFIDENTIAL", "สำเนาถูกต้อง") พร้อมปรับความโปร่งแสง
11. **ใส่เลขหน้า PDF (Page Numbers)** — เพิ่มหมายเลขหน้าอัตโนมัติตามรูปแบบที่ต้องการ เช่น "Page 1 of 10"

### 🖼️ หมวดหมู่รูปภาพ:
12. **รูปภาพเป็น PDF (Images to PDF)** — นำรูปภาพหลายๆ รูป (JPG, PNG, WebP) มารวมเป็นเล่ม PDF สามารถเลือกขนาดกระดาษ A4 หรือพอดีกับภาพ และเลือกแนวตั้ง/แนวนอนได้
13. **แปลงฟอร์แมตรูปภาพ (Image Converter)** — แปลงข้ามฟอร์แมตระหว่าง PNG, JPG, WebP, AVIF, TIFF
14. **ปรับขนาดรูปภาพ (Resize Image)** — กำหนดขนาด Width และ Height ในหน่วยพิกเซล พร้อมปุ่มล็อกสัดส่วน (Maintain Aspect Ratio)
15. **บีบอัดลดขนาดรูปภาพ (Compress Image)** — ปรับลดขนาดไฟล์ภาพพร้อมสไลเดอร์เลือกระดับคุณภาพ (10% - 95%) และแสดงผลเปรียบเทียบขนาดก่อน-หลัง
16. **หมุน & กลับด้านรูปภาพ (Rotate & Flip)** — หมุนภาพ 90°, 180°, 270° และพลิกด้านภาพแนวนอน (กระจกเงา) หรือแนวตั้ง

## 🎨 จุดเด่นด้าน UI & ประสบการณ์ใช้งาน
- **Glassmorphic Design**: สไตล์กระจกโปร่งแสง มีแสงไฟนีออนเคลื่อนไหว (Ambient Animated Glow)
- **โหมดมืด / โหมดสว่าง (Dark & Light Theme)**: มีปุ่มสลับธีมมุมขวาบน บันทึกค่าอัตโนมัติ
- **ระบบค้นหา & กรองหมวดหมู่**: พิมพ์ค้นหาเครื่องมือได้ทันที หรือกดแท็บหมวดหมู่
- **Drag & Drop Upload**: ลากไฟล์มาวางในช่องได้ทันที พร้อมแสดงรายการและปุ่มลบไฟล์
- **แถบแสดงความคืบหน้า (Progress Bar)**: แสดงเปอร์เซ็นต์และขั้นตอนการทำงานแบบเรียลไทม์
- **สรุปผลการประหยัดขนาดไฟล์**: แสดงขนาดก่อนและหลังการบีบอัดพร้อมคำนวณ % ที่ประหยัดได้
